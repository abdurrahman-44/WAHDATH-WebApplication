# Qur'an data source

- **Arabic text**: Uthmani script, from The Noble Qur'an Encyclopedia (quranenc.com)
- **English translation**: Saheeh International (Umm Muhammad), sourced via Tanzil.net
- **Packaged by**: the `quran-json` npm package (https://github.com/risan/quran-json)
- **License**: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0) —
  see `LICENSE-quran-data.txt` in this folder.

This is real Quran text and a named, licensed translation — not AI-generated and not
paraphrased. The app must always show the translator/source alongside any verse it
displays (see `About` page and the Qur'an/AI screens).
